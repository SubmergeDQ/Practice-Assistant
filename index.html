题库格式说明（点击展开）

题库支持 JSON 与 TXT 两种格式，任选其一。JSON 结构严谨、字段可扩展，推荐使用；TXT 便于手写，按固定关键字排版即可。

一、JSON 格式

顶层可以是对象（含 title 与 questions），也可以直接是题目数组。

{
  "title": "计算机网络基础",
  "questions": [
    {
      "type": "single",
      "stem": "HTTP 协议默认使用的端口号是？",
      "options": ["A. 21", "B. 25", "C. 80", "D. 443"],
      "answer": "C",
      "explanation": "HTTP 默认端口 80，HTTPS 为 443。",
      "score": 5
    },
    {
      "type": "multiple",
      "stem": "下列属于 TCP 特点的有？",
      "options": { "A": "面向连接", "B": "可靠传输", "C": "无连接" },
      "answer": ["A", "B"],
      "score": 10
    },
    {
      "type": "judge",
      "stem": "UDP 是无连接协议。",
      "answer": true
    },
    {
      "type": "blank",
      "stem": "IPv4 地址长度为____位。",
      "answer": "32",
      "explanation": "IPv4 使用 32 位地址。"
    }
  ]
}

二、TXT 格式

用 [单选] [多选] [判断] [填空] 声明题型，每题以「答案：」结束，题与题之间用空行分隔。

# 题库标题写在这里
[单选]
1. HTTP 协议默认使用的端口号是？
A. 21
B. 25
C. 80
D. 443
答案：C
分值：5
解析：HTTP 默认端口 80，HTTPS 为 443。

[多选]
2. 下列属于 TCP 特点的有？
A. 面向连接
B. 可靠传输
C. 无连接
答案：AB
分值：10

[判断]
3. UDP 是无连接协议。
答案：正确

[填空]
4. IPv4 地址长度为____位，IPv6 为____位。
答案：32||128

三、字段对照表

字段必填说明
type是single / multiple / judge / blank，也可写「单选题」「多选题」「判断题」「填空题」
stem是题干文本
options选择题必填数组或对象；元素可写 "A. 内容"，也可直接写内容（自动按 A/B/C 编号）
answer是单选："C"；多选："AC" 或 ["A","C"]；判断：true/false 或「正确/错误」；填空："答案" 或 ["答案1","答案2"]
explanation否解析文本，无解析时不显示解析区
score否本题分值，缺省为 5 分

填空题多个空之间用 || 分隔；同一个空的多个可接受答案用 | 分隔，例如 答案：IP地址|IP 地址。完整说明见项目根目录的 README.md。

手上有 Word、PDF 或图片题目，不想手动排版？点上方「下载题库生成说明」，把它和题目材料一起发给 AI，即可自动生成符合本格式的题库。
