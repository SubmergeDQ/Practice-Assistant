# 在线题库目录

放在这个目录里的题库文件，可以直接在网页上通过「选择在线题库」按钮载入，不用每次手动上传。

## 怎么加一个题库

1. 把题库 JSON（或 TXT）放进本目录，文件名建议用英文，例如 `2026-spring-math.json`；
2. 在 `index.json` 的 `banks` 数组里加一项：

```json
{
  "name": "显示在面板里的名字",
  "file": "2026-spring-math.json",
  "count": 50,
  "score": 100,
  "types": { "single": 40, "multiple": 10 }
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 是 | 面板里显示的名称，可以写中文 |
| `file` | 是 | 本目录下的文件名，要带扩展名 |
| `count` | 否 | 总题数，面板第一行显示「共 N 题」 |
| `score` | 否 | 满分，跟在总题数后面 |
| `types` | 否 | 题型分布，键为 `single` / `multiple` / `judge` / `blank`；面板第二行按单选 → 多选 → 判断 → 填空固定顺序展示 |
| `desc` | 否 | 没写 `types` 时，可以改用一句话描述顶上 |
| `updated` | 否 | `index.json` 顶层的更新日期，仅作记录 |

3. 提交并推送。GitHub Pages 部署完成后，页面点「选择在线题库」就会看到新条目。

> 页面每次打开面板都会带时间戳重新拉取（`?t=...`），不会读到旧缓存。如果刚推送完看不到，等 20 秒左右让 Pages 构建完成。

## 题库格式

就是普通的练习助手题库，见仓库根目录的 [README](../README.md#题库格式说明)，或用页面上的「下载题库生成说明」让 AI 生成。
