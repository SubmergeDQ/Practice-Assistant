# 题库生成说明

这份说明是写给 AI 看的规则书。把它和你的题目材料（Word / PDF / 图片 / 表格）一起发给 AI，AI 就会输出一份可以直接导入「练习助手」的题库文件。

你要做的只有三件事：**准备材料 → 发给 AI → 保存并上传**。

---

## 一、三步生成题库

### 第 1 步：准备材料

把手上的题目整理成文件，Word、PDF、扫描件、手机拍的试卷、Excel 表格都可以。材料里最好带答案，有解析更好。

### 第 2 步：发给 AI

打开任意支持上传文件的 AI 对话（ChatGPT、Claude、DeepSeek、豆包、Kimi、通义千问等都可以），同时上传两样东西：

1. 这份说明（题库生成说明.md）
2. 你的题目材料（可以有多个文件）

然后发送这句话：

> 请严格按附件《题库生成说明》的规则，把附件材料里的题目整理成 JSON 题库。不要编造答案，材料里没有答案的题目请单独列出来。

### 第 3 步：保存并导入

把 AI 输出的 JSON 内容复制出来，存成 `我的题库.json`（UTF-8 编码），回到练习助手首页点击上传，就能开始练习了。

如果 AI 提示内容太长、只输出了一部分，回它一句「继续输出剩下的题目，格式保持不变」即可，它会接着往下写。

---

## 二、题库文件的结构

一个题库就是一个 JSON 文件，包含一个标题和一组题目：

```json
{
  "title": "计算机网络基础",
  "questions": [
    {
      "type": "single",
      "stem": "HTTP 协议默认使用的端口号是？",
      "options": ["A. 21", "B. 25", "C. 80", "D. 443"],
      "answer": "C",
      "explanation": "HTTP 默认端口 80，HTTPS 为 443，FTP 为 21，SMTP 为 25。",
      "score": 5
    },
    {
      "type": "blank",
      "stem": "IPv4 地址长度为____位，IPv6 地址长度为____位。",
      "answer": "32||128",
      "explanation": "IPv4 使用 32 位地址，IPv6 扩展到 128 位。",
      "score": 10
    }
  ]
}
```

字段含义：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 题库名称，显示在练习页顶部 |
| questions | 是 | 题目数组，每道题一个对象 |
| type | 是 | 题型：single 单选、multiple 多选、judge 判断、blank 填空 |
| stem | 是 | 题干原文 |
| options | 选择题必填 | 选项数组，写成 "A. 内容" 的形式；判断题、填空题不写 |
| answer | 是 | 答案，写法见下一节 |
| explanation | 否 | 解析。有就写，没有就省略整个字段 |
| score | 否 | 本题分值，不写则默认 5 分 |

---

## 三、四种题型的答案写法

| 题型 | type | answer 写法 | 例子 |
| --- | --- | --- | --- |
| 单选题 | single | 字符串，一个选项字母 | "C" |
| 多选题 | multiple | 数组，按字母升序 | ["A", "C"] |
| 判断题 | judge | 布尔值，对为 true，错为 false | true |
| 填空题 | blank | 字符串，多个空用两个竖线分隔 | "32||128" |

补充说明：

- **多选题**只有一个正确答案时也要用数组，如 ["B"]，不要写成字符串。
- **判断题**不要输出 options 字段，程序会自动生成「正确 / 错误」两个选项。
- **填空题**一个空有几种正确写法时，用单个竖线分隔，如 "IP地址|IP 地址"，用户输入任意一种都算对。
- **填空题**有几个空，题干里就要有几个连续的 4 个下划线 ____，数量必须和答案对得上。

## 四、给 AI 的提示词

如果 AI 没能正确理解上面的说明，或者你只想发一段文字过去，可以直接复制下面这段提示词（它已经包含全部规则，无需再上传文档）：

```text
【角色】
你是一名严谨的题库整理助手，负责把原始题目材料转换成 JSON 题库文件。

【输入】
我会提供一份或多份题目材料：Word 文档、PDF、图片、截图或表格。

【输出】
只输出一个合法的 JSON 对象（用 json 代码块包裹），代码块之外不要写任何多余内容，结构如下：

{
  "title": "题库名称",
  "questions": [
    {
      "type": "single",
      "stem": "题干原文",
      "options": ["A. 选项一", "B. 选项二", "C. 选项三", "D. 选项四"],
      "answer": "C",
      "explanation": "解析原文",
      "score": 5
    }
  ]
}

【字段规则】
- type：只能是 single（单选）、multiple（多选）、judge（判断）、blank（填空）四种之一。
- stem：题干原文，必填。
- options：仅单选、多选需要，字符串数组，统一写成 "A. 内容" 的形式；判断题和填空题不要输出该字段。
- answer：必填，写法见下。
- explanation：材料里有解析就照抄；没有就省略整个字段。
- score：材料里标了分值就写数字，没标就省略。

【answer 写法】
- 单选：字符串，如 "C"
- 多选：数组，按字母升序，如 ["A", "C"]；只有一个答案也用数组，如 ["B"]
- 判断：布尔值，对 / 正确 / √ 用 true，错 / 错误 / × 用 false
- 填空：字符串。一个空直接写答案，如 "北京"；多个空按顺序用两个竖线分隔，如 "32||128"；同一个空有多种正确写法用单个竖线分隔，如 "IP地址|IP 地址"

【硬性要求】
1. 逐题输出，题目数量必须与材料完全一致，不得合并、拆分、跳过或改写题意。
2. 材料里没有答案的题目，answer 填空字符串，并在 JSON 之后用一句话列出这些题的题号提醒我补充。绝对不要自己编答案。
3. 不要编造解析。材料没有解析就省略 explanation 字段。
4. 题干、选项、解析照抄原文，只允许清理多余空格和换行，不要润色、不要增删内容、不要翻译。
5. 选项前缀统一用 A. B. C. D.；原文若用 ①②③、1.2.3. 或 （A）（B），请转换成字母。
6. 填空题题干里，每个空用连续 4 个下划线 ____ 表示，下划线的组数必须等于 answer 中两个竖线分隔出的段数。
7. 输出必须是严格合法的 JSON：英文双引号、不能有注释、不能有尾随逗号、字符串里不能有裸换行。
8. 题目很多时，先输出能输出的部分，最后注明「已输出 X 题，还有 Y 题未输出」；我回复「继续」后接着输出剩余题目，仍用同一个 JSON 结构，不要重复 title，也不要从头再来。

【可选：补写解析】
如果材料没有提供解析，你也可以为每道题补写 1～2 句简明解析，说明答案依据。
（不需要 AI 补写解析的话，把这一整段删掉。）

【输出前自查】
- 题目总数等于材料里的题目数
- 每道题都有 stem 和 answer
- 单选 answer 是字符串，多选 answer 是数组，判断 answer 是 true 或 false
- 填空题下划线的组数等于 answer 中竖线分隔的段数
- JSON 能被解析，没有语法错误

现在开始。材料模糊、看不清或题目有歧义时，先问我，不要猜。
```

## 五、拿到结果后怎么验收

把 AI 的输出粘贴到任意 JSON 校验网站（搜「JSON 在线校验」）看一眼，再对照这份清单：

- [ ] 题目总数和原始材料一致，没有漏题、没有重复
- [ ] 每道题都有 stem 和 answer
- [ ] 多选题的 answer 是数组，不是字符串
- [ ] 判断题的 answer 是 true 或 false，不是「对」「正确」这类文字
- [ ] 填空题题干里 ____ 的组数，等于答案里竖线分隔的段数
- [ ] 解析是材料原文，没有被 AI 添油加醋
- [ ] 最后能正常上传，页面没有报错（有黄色提示条说明个别题目有问题，按提示改即可）

## 六、常见问题

**Q：材料里没有答案怎么办？**

可以让 AI 先整理题目、把答案留空，再由你自己补。注意：AI 猜出来的答案经常是错的，尤其是多选和填空，一定要自己核对。补答案时把 answer 字段填上即可。

**Q：图片拍得不清楚，AI 认错字了怎么办？**

把模糊的地方单独截图再发一次，或者直接把那几道题的原文打给 AI。验收时重点看专业术语和数字，这两类最容易被 OCR 认错。

**Q：题目太多，一次输出不完整怎么办？**

按章节拆成几个文件，或者让 AI 分批输出（提示词里已包含分批规则）。每一批的格式必须一样，最后把 questions 数组拼接起来即可。

**Q：AI 输出的 JSON 上传时报错？**

九成是这三种情况：多了尾随逗号、用了中文引号、字符串里有没转义的换行。粘到 JSON 校验网站上看红字提示的位置，改掉即可。

**Q：可以直接生成 TXT 格式吗？**

练习助手也支持 TXT 题库（`[单选]`、`答案：C` 这种写法），适合手写。但让 AI 生成时建议一律用 JSON，结构更可靠、不容易出错。

**Q：题库里有敏感或涉密内容吗？**

注意：上传题库时数据只留在你自己的浏览器里，但把材料发给第三方 AI 时，内容会经过对方服务器。涉密材料请先脱敏。
